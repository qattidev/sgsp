# M7 — executable integration example

Status: implementation, automated example suite, and local direct/bootstrap
operator exercises pass; the fresh-checkout operator exercise should still be
repeated before a release claim.

The implementation is committed in the project history. `examples/action` has a 128 Hz
authoritative loop, sequenced input/update traffic, an operation-ID reliable
command, typed inventory request/reply, raw stream transfer, epoch-aware game
inbox, direct mode, and two-owner bootstrap mode. Its README lists the local
CA/development-identity commands without requiring a REST service or database.

Covered scenarios: `TestActionDirectProtocol`,
`TestActionReconnectResumesAuthoritativeSession`,
`TestActionBootstrapTwoClientsShareOwner`, and
`TestActionOwnerTerminationDoesNotRelocateGroup`.

Current evidence, executed on 2026-09-22 with Go 1.27.1 on linux/amd64:

```text
go test -race -count=1 ./examples/action
  selected example tests: 4; exit 0; duration 7.658s
```

This proves the automated local-QUIC scenarios. A release handoff still needs
an operator to run the documented direct and bootstrap commands from a fresh
checkout and retain that invocation record.

checkout, is retained outside Git under `artifacts/`: direct mode used an

`artifacts/action-direct-20260923-2/`; its client completed the authoritative
