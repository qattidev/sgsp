# M0 — establish the module and test harness

Status: complete on the current worktree.

The nested `qattidev/sgsp` Go 1.27.1 module owns the public API and package
layout defined in ARCHITECTURE.md section 2. Endpoint, wire, transport,
authentication, and placement behavior remains deliberately unimplemented;
those milestones must not be represented as complete by this report.

The deterministic `internal/testutil` harness supplies a manually advanced
clock, context-aware barrier, and bounded fake datagram transport. The fake
transport independently controls blocking writes, delivery, reset, loss, and
reordering, and exposes live-task and budget counters.

Checks run from the module root:

```text
go env GOMOD                 exit 0
go list ./...                exit 0
go test -count=1 ./...       exit 0
go vet ./...                 exit 0
gofmt -l .                   exit 0 (no output)
```

Environment: `go version go1.27.1 linux/amd64`.

The API signature example is `examples/api`. QUIC and JWT dependencies are
pinned in `go.mod`; their adapter/helper behavior is deferred to M2/M4.
