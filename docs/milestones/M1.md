# M1 — framing and errors

Status: complete on the current worktree.

Implemented pure, transport-free SGSP codecs in `internal/wire`:

- shortest-form QUIC variable-length integers, including truncation and
  non-minimal-encoding rejection;
- reliable-channel frames, one-event datagrams, request/response frames, and
  custom-stream headers with pre-allocation length checks;
- strict control JSON validation (UTF-8, a single object root, duplicate-key
  rejection, depth limit, required operation shapes, and capabilities);
- literal vectors in `internal/wire/testdata/golden_vectors.json`, consumed by
  `TestGoldenVectorTestdata` in addition to independent literal assertions.

The root package declares the stable numeric code space and `Error` shape.
Endpoint-specific conversion to wire errors remains an M2+ concern.

Checks run from the module root with `GOCACHE=/tmp/sgsp-go-build` because the
managed workspace does not permit writing the default Go build cache:

```text
go test -count=1 ./...                                      exit 0
go test -race -count=1 ./...                                exit 0
go vet ./...                                                exit 0
gofmt -l .                                                  exit 0 (no output)
go test ./internal/wire -run '^$' -fuzz '^FuzzControl$' -fuzztime=60s  exit 0 (61.1s)
go test ./internal/wire -run '^$' -fuzz '^FuzzEvent$' -fuzztime=60s    exit 0 (60.1s)
go test ./internal/wire -run '^$' -fuzz '^FuzzRequest$' -fuzztime=60s  exit 0 (60.1s)
```

Environment: `go version go1.27.1 linux/amd64`.

The wire tests cover the M1-applicable named scenarios: `TestGoldenVectors`,
`TestFrameBoundaries`, `TestMalformedControl`, `TestStreamRoles`, and
`TestDatagramValidation`. QUIC-capability/channel/cancellation scenarios are
intentionally deferred to M2, where they can exercise an actual transport.
