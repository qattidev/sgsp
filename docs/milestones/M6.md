# M6 — placement and group lifecycle

Status: memory and PostgreSQL adapter implementation is present; the current
PostgreSQL integration gate is incomplete because this environment has no
`SGSP_TEST_DATABASE_URL`.

Implementation baseline revision: `084aa73fcca2cfe3a4bc4e80542e341884b5fe91`.
Current PostgreSQL integration-coverage revision: `db53607bba0a64f5faa00637fd056da3310c18e6`.
The implementation is committed; it includes bootstrap resolve, deterministic
owner selection, in-memory registry/store, PostgreSQL store and migrations,
signed admission binding, group-close persistence hooks, owner-health behavior,
and direct-resume independence from placement.

Covered Architecture.md section-13.4 IDs: `TestConcurrentAssignment`,
`TestAssignmentVersionAndClose`, `TestAdmissionBinding`, `TestPlacementOutage`,
`TestUnhealthyOwner`, `TestOwnerRestart`, `TestGroupCloseRace`, and
`TestDraining`.

The nested integration module also has `TestMigrationReapplicationAndDrift`.
Its disposable-schema helper applies the embedded migration twice as a no-op;
the test then changes only that schema's recorded checksum and requires
`ErrMigrationDrift`. `TestConcurrentBootstrapResolve` creates two separate
PostgreSQL adapters and bootstrap instances sharing the same disposable
schema, then barrier-starts 100 resolves and requires one stored owner.
`TestBootstrapCloseRace` similarly barrier-starts 100 close calls across the
two bootstrap instances, requires every close to be idempotent, and requires a
later resolve to return `ErrGroupClosed`. Together these exercise the SQL
store's shared-winner and durable-closure paths rather than only direct store
calls. They compiled on the current worktree without a database connection,
but still require the configured disposable database to execute. Before
migration, the same helper holds four separate pooled connections and requires
each `current_schema()` to be the generated schema. It then verifies that
`sgsp_schema_migrations` belongs to that schema, not the database default
schema. These checks protect the required per-connection `search_path` setup.
