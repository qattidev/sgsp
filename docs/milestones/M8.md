# M8 — release evidence

Status: incomplete. The harness is implemented and its retained tooling
evidence passes, but the required sustained capacity, impairment, plateau, and
published comparison campaign has not been completed.

Revision: `084aa73fcca2cfe3a4bc4e80542e341884b5fe91`, with the current
uncommitted implementation worktree. `cmd/sgspbench`,
`cmd/sgspbenchreport`, and `internal/udprelay` implement the bounded,
deterministic two-socket UDP relay harness, separately built binaries,
per-trial JSON, fixed-memory timing histograms, correlated directional local
budgets, runtime counters, relay backlog, queue/drop observations, and a
bare-QUIC baseline. The runner accepts only repository-local `artifacts/`
paths and refuses `/tmp`. Warmup and measurement use separate workload
generations, and phase-marked datagrams, requests, and bulk streams prevent
late warmup traffic from contaminating measurement counters. A trial also
records missed scheduled input/request/bulk ticks and is invalid if its
generator could not sustain the configured schedule.

Current verification, executed on 2026-09-22 with Go 1.27.1 on linux/amd64:

```text
go test -count=1 ./cmd/sgspbench ./cmd/sgspbenchreport
  selected package suites: 2; exit 0; duration 3.704s
go test -race -count=1 ./...
  complete module suite; exit 0; root-package duration 106.339s
SGSPBENCH_WARMUP=50ms SGSPBENCH_DURATION=1100ms \
  SGSPBENCH_HEALTHY_CLIENTS='1' SGSPBENCH_GOMAXPROCS=1 \
  scripts/run-benchmark-matrix.sh artifacts/measurement-availability-smoke-20260922
  selected trials: 20; completed: 20; exit 0; duration about 29s
```

The latter artifact retains `campaign.json`, exact binaries, environment
metadata, raw JSON, run log, and rendered summary. It verifies schema wiring:
SGSP trials report local queue/drop measurements while bare-QUIC trials render
those library-only fields unavailable. Its 50 ms warmup and 1.1 s measurement
do not establish capacity or a performance target.

The older retained one-client full sweep at
`artifacts/healthy-1c-full-20260922/` is preserved, but was captured before
the phase-separated boundary accounting above. Its counters may include late
warmup work, so it is diagnostic evidence only and cannot support a capacity
or release claim. It also records 11--22 local/coalesced SGSP datagram drops
at 128 Hz (about 0.15--0.29% of offered inputs/updates), exceeding the
architecture's below-0.1% sequenced-replacement criterion for that profile.

Two later local boundary-validation matrices are retained at
`artifacts/measurement-boundary-smoke-20260922/` and
`artifacts/measurement-boundary-readiness-smoke-20260922/`. Each records all
20 trials with no offered/accepted/delivered boundary inversion. The latter
also demonstrates the generator validity signal: all trials are invalid on
this constrained host because their input and/or 10 ms bulk tickers missed
scheduled work. These are harness diagnostics, not performance results.

Still required before M8 can pass: five-seed 60-second healthy capacity and
plateau evidence; the full 20/50/100 ms, loss, jitter, reorder, 60/128 Hz
impairment matrix at half the established healthy capacity; published SGSP
versus bare-QUIC interpretation; current extended fuzz and PostgreSQL
integration evidence; and preserved output for every failed performance gate.
