# M8 — release evidence

Status: incomplete. The harness is implemented and its retained tooling
evidence passes, but the required sustained capacity, impairment, plateau, and
published comparison campaign has not been completed.

Benchmark harness correctness revision: `3d8e043`; evidence-manifest revision:
`2f97f93`. `cmd/sgspbench`, `cmd/sgspbenchreport`, and `internal/udprelay`
implement the bounded, deterministic two-socket UDP relay harness, separately
built binaries, per-trial JSON, fixed-memory timing histograms, correlated
directional local budgets, runtime counters, relay backlog, queue/drop
observations, and a bare-QUIC baseline. The runner accepts only
repository-local `artifacts/` paths and refuses `/tmp`; each environment
manifest retains the exact `go build` command for both binaries. Warmup and
measurement use separate workload generations, and phase-marked datagrams,
requests, and bulk streams prevent late warmup traffic from contaminating
measurement counters. A trial also records missed scheduled
input/request/bulk ticks and is invalid if its generator could not sustain the
configured schedule.

`scripts/run-fuzz-campaign.sh` provides the corresponding retained-evidence
runner for the extended wire fuzz gate. It defaults to ten minutes each for
`FuzzControl`, `FuzzEvent`, and `FuzzRequest`, records the Go toolchain and
actual elapsed duration, and retains its campaign manifest, local Go cache,
per-target logs/status JSON, and summary below a repository-local
`artifacts/` directory. Its eight-second `FuzzControl` smoke at
`artifacts/fuzz-runner-smoke-20260923/` completed successfully and verifies
the continuous runner's output only; it is not extended fuzz evidence. The
two-slice `FuzzControl` smoke at `artifacts/fuzz-slice-smoke-20260923/`
additionally verifies that a partial target exits nonzero and only becomes
complete after its retained, resumed final slice succeeds. Run the full gate
continuously with:

```text
scripts/run-fuzz-campaign.sh artifacts/fuzz-YYYYMMDDTHHMMSSZ
```

Where the execution environment enforces a shorter per-process limit, the
same ten-minute total is explicitly recorded as 24 resumable 25-second slices:

```text
SGSP_FUZZ_DURATION=10m SGSP_FUZZ_SLICE_DURATION=25s \
  SGSP_FUZZ_SLICES=24 SGSP_FUZZ_MAX_SLICES_PER_INVOCATION=1 \
  scripts/run-fuzz-campaign.sh artifacts/fuzz-YYYYMMDDTHHMMSSZ
# Repeat the same command with SGSP_FUZZ_RESUME=1 until the target is complete.
```

The runner rejects a sliced campaign whose slice count and duration do not
equal its recorded requested duration, and retains a status update after every
successful slice.
