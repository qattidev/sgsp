# M8 — release evidence

Status: incomplete. The harness, extended wire fuzzing, ten-minute
slow-consumer plateau, and M6 disposable-PostgreSQL evidence pass, but the
required sustained capacity, impairment, and published comparison campaign

Benchmark harness correctness revision: `3d8e043`; evidence-manifest and
reference-host preflight and terminal-status revisions: `2f97f93`,
`5fec38d`, `3d9ed7a`, and `90f19e3`.
`cmd/sgspbench`, `cmd/sgspbenchreport`, and `internal/udprelay` implement the
bounded, deterministic two-socket UDP relay harness, separately built
binaries, per-trial JSON, fixed-memory timing histograms, correlated
directional local budgets, runtime counters, relay backlog, queue/drop
observations, and a bare-QUIC baseline. The runner accepts only
repository-local `artifacts/` paths and refuses `/tmp`; each environment
manifest retains the exact `go build` command for both binaries. With
`SGSPBENCH_REFERENCE_HOST=1`, it refuses capacity runs unless the documented
host minimums hold: four physical cores, 8 GiB RAM, and GOMAXPROCS=4. Warmup
and measurement use separate workload generations, and phase-marked
datagrams, requests, and bulk streams prevent late warmup traffic from
contaminating measurement counters. A trial also records missed scheduled
input/request/bulk ticks and is invalid if its generator could not sustain the
configured schedule. Every final campaign also retains `evaluation.md`, which
re-checks its raw JSON against the expected plan, gives an explicit matrix
verdict, identifies the highest healthy benchmark-local capacity, checks the
half-capacity impairment matrix, compares SGSP to bare QUIC, and lists only
evidence-supported limitations. `evidence.sha256` binds the retained binaries,
raw results, manifests, codec output, summary, and evaluation (but not the
live run log or local Go cache) for later integrity checking.
