# M5 — continuity and terminal cleanup

Status: complete on the current worktree. The architecture's broader release
gate remains subject to M8 evidence.

The implementation is committed in the project history. Sessions retain one logical identity,
attachment, principal, directional budgets, resume secret, and owner through
transport replacement. The owner alone increments epochs. Resume authentication
and fencing precede attachment commit; terminal sessions are retained in a
bounded cache.

The private server clock seam keeps the production API unchanged while letting
`TestResumeGrace` advance a deterministic clock to grace-minus-one nanosecond
and exactly at grace. `TestResumeGraceHonorsEarlierAuthenticationExpiry`
verifies that an earlier credential deadline produces `AuthExpired` rather
than `SessionExpired`.
